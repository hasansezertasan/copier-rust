# Repository tooling

How this repository's own tooling is arranged.

## Lint configs live under `.config/`

**Id:** 72c8bf82-5c70-4041-8887-90735db9cbe5
**Type:** decision
**Status:** active
**Evidence:** confirmed
**Source:** `AGENTS.md`; maintainer statement, 2026-10-24

Lint configs sit under `.config/`, never at the repo root. Tools that cannot read from there live elsewhere: Renovate and release-please in `.github/`, EditorConfig as `.editorconfig` at the root.

**Reason:** the maintainer does not want clutter in the repository root.

**Rejected alternative:** leaving the configs at the root, where tools find them by default. Other alternatives were not recorded.

## cobo-managed boilerplate, checked weekly

**Id:** 483e288a-bdb2-4e34-baed-03f3eb9450cd
**Type:** decision
**Status:** active
**Evidence:** confirmed
**Source:** `AGENTS.md`; the comment in `.github/workflows/cobo-drift.yml`
**Revisit when:** cobo stops needing a network fetch to detect drift

`.gitignore`, `.gitattributes` and `.editorconfig` are generated by cobo, tracked in `cobo.lock`, seeded once and owned by the project afterwards. The drift check runs `cobo update && cobo check` weekly and on demand, never on `pull_request`.

**Reason:** `cobo update` hits the network and is inherently flaky, so the check is a maintenance signal rather than a merge blocker.

**Rejected alternative:** running the drift check on every pull request, rejected because of that flakiness.

## Tool pins sit where Renovate's native managers read them

**Id:** 4f91260c-e1e8-43ac-ae8f-f32bf10b94f0
**Type:** decision
**Status:** active
**Evidence:** confirmed
**Source:** `AGENTS.md`; `.config/mise.toml` comments

Tool versions are pinned in `.config/mise.toml` for Renovate's native `mise` manager. The Python version is the exception: it lives in `.python-version`, which `mise.toml`, uv and Renovate all read (`PYTHON_VERSION` overrides it in mise), and it is seeded once and owned afterwards.

**Reason:** one file serves three readers, and native managers cover every entry without a hand-written regex.

**Rejected alternative:** a regex-based custom Renovate manager, not used; unknown whether it was ever tried here.
